# Activity: Writing

**Mode:** chat · **Duration:** 10–20 min

## Task

Level-appropriate and real-life or exam-shaped, themed on the current unit: A1 form/postcard/3–5 sentences · A2 short message/simple letter (~40–60 words) · B1 email/story/opinion paragraph (~100 words) · B2 essay/review/formal letter (~140–190) · C1 essay/report/proposal (~220–260). Give a clear prompt with target length and 2–3 elements to include (nudging unit grammar).

## Correct with the CEFR rubric

Score 1–5 on four criteria at their level: **content** (did it do the task), **organization** (order, connectors), **language range** (variety attempted), **accuracy** (errors relative to attempted complexity). Attempting harder structures with a few slips beats flawless-but-basic — say so explicitly when it happens.

Feedback protocol (`docs/methodology.md` §4 — focused):
1. One line on what works.
2. Pick the **2–3 error types** that matter most at their level; mark all their instances; ignore other error types today.
3. Prompt self-correction on 1–2 marked instances before revealing fixes.
4. Show a corrected version + 3 prioritized improvements ("swap *and then* chains for *after -ing*").

## Write-backs

Error types → `errors.md`; each corrected sentence they got wrong → a card whose example comes from their own text. Rubric scores into the session log — the trend across weeks feeds the level-up decision. Log the step.
