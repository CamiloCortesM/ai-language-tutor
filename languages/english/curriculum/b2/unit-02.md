# B2 · Unit 02 — Crossed timelines

**Can-do:** I can connect a past cause to a present result, and a present fact to a past result, using mixed conditionals.

## Grammar focus
Mixed conditionals cross two time zones inside one sentence. The **past → present** mix uses *if + past perfect, would + base verb*: an unreal past causes an unreal present ("If I had saved money, I would be rich now"). The **present → past** mix uses *if + past simple, would have + past participle*: a permanent present fact explains an unreal past ("If I were more careful, I wouldn't have crashed"). Choose the mix by asking which time each half refers to. Time words such as *now*, *today*, *still* or *last year* signal the shift between the two halves.

- If I **had taken** that course, I **would have** a better job today.
- She **would be** fluent now if she **had kept** practising.
- If he **weren't** so stubborn, he **wouldn't have lost** those clients.
- We **would still be** friends if you **hadn't lied** to me.
- If they **had invested** earlier, they **wouldn't be** in debt now.
- I **wouldn't be** so tired today if I **had slept** properly.
- If I **spoke** German, I **would have understood** the meeting yesterday.

## Target vocabulary (10–12 items)
consequence — a result that follows from an action
long-term — lasting or affecting a long period of time
outcome — the final result of a process or event
circumstances — the conditions that affect a situation
trade-off — a balance between two things you cannot both have fully
inevitable — certain to happen and impossible to avoid
hindrance — something that makes progress difficult
priority — something treated as more important than others
setback — a problem that delays or reverses progress
foresee — to know or expect that something will happen
alter — to change something slightly
knock-on effect — an indirect result caused by an earlier event

## Functions & phrases
- Linking cause and result: "That's why…", "As a result…"
- Reflecting on paths: "If things had gone differently, I'd probably be…"
- Weighing choices: "It was a trade-off between time and money."

## Suggested activities
- reading: a profile of someone whose single past decision still shapes their present.
- conversation: "cause and effect" — trace one past choice to a present situation.
- quiz focus: choosing the correct mix (past→present vs present→past) from the time signals.

## Watch out
- If I studied medicine, I would be a doctor now → If I had studied medicine, I would be a doctor now
- If I would be taller, I would have played basketball → If I were taller, I would have played basketball
- I would be rich if I invested then → I would be rich if I had invested then
- If she wouldn't have lied, we would still be friends → If she hadn't lied, we would still be friends
